# PRAVA AI

O‘zbekiston uchun o‘zbek tilidagi haydovchilik nazariyasi va amaliy ko‘nikmalar platformasi.

## Hozirgi bosqich
- Next.js App Router + TypeScript
- Tailwind CSS
- Responsive Uzbek-language landing/dashboard prototype
- B category first; architecture intended to expand to other categories

## Local development
```bash
npm install
npm run dev
```

## Environment
Supabase and AI credentials will be added server-side in later stages. Never expose service-role keys or AI API keys in client-side code.

## Roadmap
1. Foundation and responsive interface
2. Supabase Auth, profiles and secure database policies
3. Officially sourced B-category theory and road-sign lessons
4. Test engine, timers, explanations and progress tracking
5. AI instructor with source-grounded answers
6. Driving practice and simulator modules
7. Admin tools, premium entitlements and deployment checks

> Learning software and simulation do not replace official training or supervised real-world driving.
